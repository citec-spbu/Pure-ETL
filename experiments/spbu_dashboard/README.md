# SPBU Research Collaboration Dashboard


Интерактивный дашборд для анализа сети научного сотрудничества на основе данных, полученных из OpenAlex API. Система позволяет исследовать связи соавторства между учёными, анализировать публикационную активность, цитируемость работ и основные направления исследований.

Дашборд реализован с использованием библиотек Dash, Plotly, Cytoscape и NetworkX.

---

## Основные возможности

* Cбор данных из OpenAlex.
* Построение сети соавторства исследователей.
* Интерактивная визуализация научных связей.
* Фильтрация авторов по количеству публикаций и цитирований.
* Просмотр подробной информации об авторе.
* Анализ динамики публикационной активности.
* Анализ наиболее популярных тематик исследований.
* Масштабирование и перемещение вершин графа.

---

## Архитектура системы

Работа приложения состоит из следующих этапов:

```text
OpenAlex API
      │
      ▼
Получение публикаций
      │
      ▼
Построение графа соавторства
      │
      ▼
Визуализация и анализ в Dash
```

---

## Основные функции

### `get_author_id(display_name)`

Выполняет поиск автора в OpenAlex и возвращает его уникальный идентификатор.

**Входные данные:**

* имя автора.

**Выходные данные:**

* идентификатор автора OpenAlex.

---

### `get_author_works(author_id)`

Получает список публикаций выбранного автора.

**Входные данные:**

* идентификатор автора OpenAlex.

**Выходные данные:**

* список публикаций.

---

### `fetch_all_data()`

Собирает публикации всех авторов, указанных в списке `MAIN_AUTHORS`, и удаляет дублирующиеся записи.

**Выходные данные:**

* словарь уникальных публикаций.

---

### `extract_paper_info(work)`

Извлекает из публикации основные метаданные.

**Извлекаемые параметры:**

* название публикации;
* список авторов;
* количество цитирований;
* год публикации;
* название журнала или конференции;
* тематики исследования.

**Выходные данные:**

* словарь с метаданными публикации.

---

### `build_coauthorship_graph(works_data)`

Строит граф соавторства с использованием библиотеки NetworkX.

Каждый автор представляется вершиной графа.

Ребро между двумя вершинами создаётся в случае совместного участия авторов в одной или нескольких публикациях.

Для каждой вершины сохраняются следующие характеристики:

* количество публикаций;
* суммарное число цитирований;
* принадлежность к группе основных авторов.

Для каждого ребра сохраняется:

* количество совместных публикаций (`weight`).

**Выходные данные:**

```python
networkx.Graph
```

---

### `graph_to_cytoscape_elements(G)`

Преобразует граф NetworkX в формат, пригодный для отображения в Dash Cytoscape.

**Выходные данные:**

* список вершин;
* список рёбер.

## Компоненты дашборда

### Сеть соавторства

Основной элемент интерфейса — интерактивный граф научного сотрудничества.

Особенности визуализации:

* размер вершины зависит от количества публикаций автора;
* цвет вершины отражает принадлежность к определённой группе авторов;
* поддерживаются масштабирование и перемещение графа.

Цветовая схема:

* красный цвет — "основные" исследователи - те, чьи данные мы взяли из OpenAlex;
* остальные цвета — их соавторы.

---

### Панель информации об авторе

При выборе вершины отображается информация об авторе:

* полное имя;
* количество публикаций;
* число цитирований;
* количество соавторов;
* принадлежность к группе "основных" авторов;
* список всех соавторов.

---

### Панель фильтрации

Поддерживаются следующие фильтры:

* минимальное количество публикаций;
* минимальное количество цитирований;
* переключение между сокращёнными и полными именами авторов.

---

### Диаграмма тематик исследований

Отображает наиболее часто встречающиеся направления исследований на основе тематических меток OpenAlex.

---

### Диаграмма публикационной активности

Показывает распределение публикаций по годам для авторов, вошедших в текущую выборку после применения фильтров.

```bash
python spbu_dashboard.py
```

```text
http://127.0.0.1:8050
```
