\## Результаты 1го этапа 



Исходный файл `Data/research-outputs.json` содержит 1000 публикаций



В ходе исследования были определены точные пути к основным данным:



\* идентификатор публикации — `uuid`;

\* название — `title.value`;

\* год — `publicationStatuses\[].publicationDate.year`;

\* идентификатор внутреннего исследователя — `personAssociations\[].person.uuid`;

\* полное имя — `personAssociations\[].person.name.text\[].value`;

\* аннотация — `abstract.text\[].value`;

\* структурированные и свободные ключевые слова — элементы `keywordGroups`;

\* подразделения автора — `personAssociations\[].organisationalUnits`.



Сформирована нормализованная таблица «исследователь — публикация»:



```text

output/researcher\_publications.csv

```



Основные результаты:



\* 1000 публикаций;

\* 2338 авторских связей;

\* 1420 связей с внутренними исследователями;

\* 918 внешних авторов без внутреннего UUID;

\* 830 уникальных внутренних исследователей;

\* 1420 строк в итоговой таблице;

\* 0 повторных пар «исследователь — публикация»;

\* 0 публикаций без внутреннего исследователя



Генерируемые CSV-файлы из папки `output` не сохраняются в Git. Их можно восстановить запуском:



```powershell

uv run build-researcher-publications

```



Подробная статистика находится в файле:



```text

reports/researcher\_publications\_summary.md

```



\## Ограничения данных



Аннотация присутствует только у части публикаций, поэтому она не может быть единственным источником публикационного профиля



Для первой версии профиля будут использоваться:



\* названия публикаций;

\* ключевые слова;

\* аннотации при их наличии;

\* типы и категории публикаций



В рекомендации включаются только внутренние исследователи со стабильным UUID. Внешние авторы учитываются в статистике, но пока не участвуют в поиске партнёров
