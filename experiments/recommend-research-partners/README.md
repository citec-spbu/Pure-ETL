# Recommendation of Potential Research Partners

Эксперимент по построению рекомендаций потенциальных научных партнёров на основе публикационных профилей исследователей

## Цель

Цель эксперимента — построить воспроизводимый pipeline, который:

1. извлекает информацию о публикациях и исследователях;
2. формирует публикационный профиль каждого исследователя;
3. оценивает тематическое сходство исследователей;
4. исключает уже существующих соавторов;
5. формирует Top-N рекомендаций потенциальных новых научных партнёров;
6. сравнивает лексический и семантический подходы;
7. выполняет offline-оценку качества рекомендаций.

## Используемые подходы

В эксперименте реализованы два способа представления публикационных профилей

### TF-IDF baseline

TF-IDF используется как простой и интерпретируемый baseline

Для тематического представления используются:

* названия публикаций;
* ключевые слова;
* аннотации — в варианте Full.

Используются два варианта профиля:

* **Core** — названия публикаций и ключевые слова;
* **Full** — названия публикаций, ключевые слова и аннотации.

Сходство исследователей рассчитывается с помощью cosine similarity

### Semantic embeddings

Второй подход использует модель:

`intfloat/multilingual-e5-small`

Для каждой публикации отдельно строится embedding, после чего embeddings публикаций одного исследователя усредняются и нормализуются

Также используются два варианта:

* **Core** — название публикации и ключевые слова;
* **Full** — название публикации, ключевые слова и аннотация.

Сходство исследователей рассчитывается по нормализованным embedding-векторам

## Учёт существующего соавторства

Пары существующих соавторов определяются по совместным публикациям

При формировании рекомендаций из списка кандидатов исключаются:

* сам исследователь;
* исследователи, с которыми у него уже есть совместная публикация.

Таким образом, рекомендации ориентированы на поиск потенциальных новых партнёров

## Оценка качества

Для offline-оценки используется восстановление скрытых связей соавторства

Для каждой подходящей пары исследователей:

1. определяются все их совместные публикации;
2. эти публикации временно исключаются из данных;
3. публикационные профили строятся без совместных работ;
4. известная связь между исследователями считается скрытой;
5. измеряется позиция скрытого соавтора среди кандидатов.

В оценке участвуют:

* **61** подходящая пара соавторов;
* **122** направленных тестовых случая.

Используемые метрики:

* `Hit@5`;
* `Hit@10`;
* `MRR`;
* `Median Rank`.

Полученные результаты:

| Метод      | Профиль |  Hit@5 | Hit@10 |    MRR | Median Rank |
| ---------- | ------- | -----: | -----: | -----: | ----------: |
| TF-IDF     | Core    |  6.56% | 11.48% | 0.0723 |        59.5 |
| TF-IDF     | Full    |  9.84% | 13.11% | 0.0886 |        76.5 |
| Embeddings | Core    | 11.48% | 19.67% | 0.0862 |        56.0 |
| Embeddings | Full    | 12.30% | 20.49% | 0.0757 |        57.0 |

Метрики используются как сравнительная offline-оценка реализованных подходов и не рассматриваются как абсолютная оценка качества потенциального научного сотрудничества

## Ограничения данных

Эксперимент выполняется на синтетическом наборе данных, предоставленном для разработки и тестирования без раскрытия реальных данных университета

Поэтому статистические характеристики набора, распределение публикаций, тематик и исследовательских связей не следует интерпретировать как характеристики реальной исследовательской деятельности университета

Цель эксперимента — разработка и проверка воспроизводимого подхода к построению публикационных профилей и рекомендаций, который потенциально может быть применён к данным аналогичной структуры
