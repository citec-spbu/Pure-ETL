# Отчёт о семантических профилях

## Метод

- Модель: `intfloat/multilingual-e5-small`
- Core: название публикации + ключевые слова
- Full: название публикации + ключевые слова + аннотация
- Embedding исследователя: среднее embeddings его публикаций
- Итоговые embeddings исследователей нормализуются по L2

## Результат

- Связей «исследователь — публикация»: **1420**
- Уник публикаций: **1000**
- Исследователей: **830**
- Размерность embedding: **384**
