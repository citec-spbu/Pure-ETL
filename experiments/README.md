# Experiments

## Описание

Папка для сохранения результатов промежуточных исследований.

## Prerequisites

Для работы потребуется установить UV.
Инструкции по установке можно посмотреть [здесь](https://docs.astral.sh/uv/getting-started/installation/).

## Порядок работы с папкой

Данная папка выступает как UV workspace.
Более подробно об этом можно узнать [здесь](https://docs.astral.sh/uv/concepts/projects/workspaces/#using-workspaces).

Во-первых, это точка входа в отдельные исследования/эксперименты.
Каждое исследование - отдельный модуль с человеко-читаемым названием.

Во-вторых, она содержит общие зависимости, которые могут быть полезны при работе над отдельным исследованием.
Это позволяет избежать ручной установки одних и тех же зависимостей в каждом модуле.
Информация об общих зависимоостях доступна в `dependencies` файла `pyproject.toml`
Полный список общих зависимостей доступен в `dependencies` в файле `pyproject.toml`.

## Создание нового исследования

### Инициализация

Каждый модуль - отдельный эксперимент.
Для создания модуля необходимо создать папку, в которой будет размещено исследование:

```shell
mkdir <your_module_name>
```

> [!WARNING]
>
> Перед созданием убедитесь, что создание папки происходит в experiments!

Для подключения модуля в workspace необходимо:

1. Перейти в папку нового модуля:

```shell
cd <your_module_name>
```

2. Инициализировать модуль:

```shell
uv init --bare
```

Если модуль был успешно связан с workspace, то в консоли должно быть похожее сообщение:

```shell
Adding `explore-persons-organisations` as member of workspace `/home/forg/my-space/projects/uni/pure/Pure-ETL/experiments`
```

### Локальная установка зависимостей

Если в ходе работы возникает необходимость подключения дополнительных зависимостей, которые нужны только в данном модуле, то можно их можно установить при помощи команды:

```shell
uv add <package_name>
```

> [!WARNING]
>
> Перед установкой убедитесь, что находитесь в нужном модуле!

Если все прошло успешно, можно посмотреть значение переменной `dependencies` в `pyproject.toml` Вашего модуля.

### Запуск

Запускаться можно разными способами.
Для этого перейдите в модуль Вашего исследования и выполните команду:

```shell
uv run jupyter lab
```

Если запуск прошел успешно, то в браузере должна открыться страница с Jupyter Lab.
Если же автоматического перенаправления не произошло, ищите в консоли сообщения с url jupyter server:

```shell

        file:/home/forg/.local/share/jupyter/runtime/jpserver-701863-open.html
    Or copy and paste one of these URLs:
        http://localhost:8888/lab?token=8c9b09717fb08f597f3611bbbde0729831f84064e64adb12
        http://127.0.0.1:8888/lab?token=8c9b09717fb08f597f3611bbbde0729831f84064e64adb12
```

и откройте его в браузере самостоятельно.

> [!NOTE]
>
> Сверху указан лишь пример такой ссылки.

Если хочется работать через VSCode, то потребуется установить расширение Jupyter.
В `.ipynb` файле нажать на `Select kernel -> Existing Jupyter Server` и ввести url сервера.
